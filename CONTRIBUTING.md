# Contributing to Get Better At Coding

We welcome lessons, exercises, and challenges across any language or topic!

## The 3-Tier Lesson Standard
Every contribution must follow our strict pedagogical blueprint:

1. **Tier 1: The Explainer:** 3-5 visual bullet points explaining the physical mental model + Native Idiom vs Rookie Anti-Pattern.
2. **Tier 2: The Socratic Scaffold:** Complete vertical slice leaving the crux open for the learner (`YOUR TURN`).
3. **Tier 3: The Verification Harness:** Runnable tests with independent ground-truth assertions (single-command execution).
